## Реализация алгоритма

Перемножение матриц `C = A × B` реализовано с помощью тройного цикла в порядке `i-k-j` (для лучшей локальности кэша):

```cpp
#pragma omp parallel for
for (int i = 0; i < N; ++i) {
    for (int k = 0; k < N; ++k) {
        double a_ik = A[i][k];
        for (int j = 0; j < N; ++j) {
            C[i][j] += a_ik * B[k][j];
        }
    }
}
```
